# یادداشت حکم 🃏

ثبت امتیاز بازی **حکم** با رابط فارسی و راست‌چین — بازسازی فلاتریِ [NoteHokm-2](https://github.com/y3fd/NoteHokm-2).

## استفاده

**آیفون (وب‌اپ):** لینک زیر را در سافاری باز کنید و گزینهٔ **افزودن به صفحهٔ اصلی** را بزنید تا مثل اپ روی هوم‌اسکرین نصب شود:

🔗 https://y3fd.github.io/notehokm/

**اندروید (APK):** آخرین نسخه در بخش [Releases](https://github.com/y3fd/notehokm/releases) موجود است.

## امکانات

- ثبت هم‌زمان امتیاز دو تیم با دکمه‌های سریع (`+۱`، `کُت`، `کُت‌خالی`)
- انتخاب و ثبت خال حکم
- فسخ دست، حذف دست با تأیید، ویرایش یادداشتٔ هر دست
- آمار زندهٔ کُت، نبرد، بیشترین امتیاز و…
- تاریخچهٔ کامل دست‌ها + آرشیو بازی‌ها (بازی قبلی با بستن اپ از بین نمی‌رود)
- تاریخ شمسی، ارقام فارسی، تم تیره

## ساخت

```bash
flutter build apk --release
flutter build web --release --base-href /notehokm/
```

آیکون از SVG ساخته شده و در `icon-512.png` همین ریپو قرار دارد.
